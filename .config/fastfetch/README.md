# Fastfetch

Конфигурация: [`config.jsonc`](./config.jsonc). Запуск: `fastfetch`.

Используется встроенный Apple logo, синий separator и иконки Nerd Font.
Выводятся: пользователь и hostname, OS, host, kernel, uptime, пакеты, shell,
терминал и шрифт, window manager, theme, display, CPU, GPU, память, корневой
диск, батарея, локальный IPv4, locale и цветовая палитра.
