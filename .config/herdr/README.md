# Herdr

Конфигурация: [`config.toml`](./config.toml), проверена на Herdr 0.9.0.
Формат и действия: [официальная документация](https://herdr.dev/docs/configuration/).

## Подключение

В `~/.config/herdr` Herdr также хранит сессии, sockets и логи.
Подключайте только файл конфига, а не весь каталог:

```sh
mkdir -p ~/.config/herdr
# Если config.toml уже существует, сначала сохраните его под свободным именем.
ln -s ~/dotfiles/.config/herdr/config.toml ~/.config/herdr/config.toml
herdr config check
herdr server reload-config
```

Последняя команда применяется к уже запущенному серверу. Если он не запущен,
достаточно выполнить `herdr`.

## Бинды

Каждая последовательность начинается с `Ctrl-B`: отпустить Ctrl, затем нажать
указанную клавишу. Работает на английской и русской раскладках, кроме `?`;
заглавная буква означает Shift.

| После Ctrl-B | Действие |
| --- | --- |
| `c` / `Shift-X` | Создать / закрыть вкладку Herdr |
| `p` / `n` | Предыдущая / следующая вкладка |
| `1`…`9` | Выбрать вкладку по номеру |
| `Shift-T` | Переименовать вкладку |
| `↑` / `↓` | Предыдущий / следующий workspace |
| `w` | Навигатор workspace-ов |
| `Shift-N` / `Shift-W` / `Shift-D` | Создать / переименовать / закрыть workspace |
| `←` / `→` | Предыдущий / следующий агент |
| `g` | Навигатор сессий |
| `h` / `j` / `k` / `l` | Фокус панели: влево / вниз / вверх / вправо |
| `v` / `-` | Разделить панель |
| `x` / `z` | Закрыть / развернуть панель |
| `b` / `?` | Показать sidebar / справку по активным биндам |
| `q` | Отсоединиться от persistent session |
| `f` | Открыть каталог активной панели в Finder |
| `Shift-O` | Закрыть остальные панели вкладки (нужен `jq`) |
| `Shift-L` | Открыть lazygit в новой панели |
| `Shift-R` | Перечитать конфиг |

Cmd-T и Cmd-W управляют внешними вкладками Ghostty; для закрытия вкладки Herdr
использовать Ctrl-B, Shift-X.
Option-сочетания заняты AeroSpace, поэтому здесь они не используются.

## Настройки и советы

- Тема `terminal`: herdr использует цвета текущего терминала.
- `new_cwd = "follow"`: новые панели и вкладки наследуют рабочую директорию.
- `hide_tab_bar_when_single_tab = true`: панель вкладок скрыта, пока вкладка одна.
- `window_title`: заголовок окна из имени workspace и заголовка терминала.
- В sidebar для Claude показан заголовок сессии вместо имени агента.
- `[experimental] pane_history = true`: экспериментальная история панелей.
- `prompt_new_tab_name = false`: вкладка создаётся сразу; имя можно задать позже.
- `confirm_close = false`: workspace закрывается без подтверждения.
- Метки агентов на границах панелей и `status_indicators = "dots"`
  помогают различать агентов и их состояния.
- Для работы без звука можно добавить `[ui.sound]` с `enabled = false`.
  Для приоритета агентов, требующих внимания, установить в `[ui]`
  `agent_panel_sort = "priority"`; порядок навигации при этом будет меняться.
- Для выхода с сохранением работающих процессов использовать Ctrl-B, q.
- Настройки, сохранённые через UI Herdr, могут менять файл конфига:
  после этого проверять `git diff` в dotfiles.

Проверка без подключения:

```sh
HERDR_CONFIG_PATH="$PWD/.config/herdr/config.toml" herdr config check
```
