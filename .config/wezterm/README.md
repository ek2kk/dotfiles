# WezTerm

Конфигурация: [`wezterm.lua`](./wezterm.lua).

- Font fallback: `JetBrains Mono`, затем `Symbols Nerd Font Mono`; размер `17pt`,
  line height `1.2`.
- Theme: `OneDark (base16)`.
- Tab bar скрыт, когда вкладка одна; используется простой, не fancy tab bar.
- Закрытие окна и вкладки не требует подтверждения.
- `Cmd-W` и `Cmd-Shift-W` закрывают текущую вкладку.
